# Beta users kit (first 5–20 people)

Use this to recruit real Moroccan testers. Do not invent users or fabricate feedback.

## Short invitation (WhatsApp / email)

```
Salut,

Je lance Mizane en bêta gratuite : analyse de CV (score ATS + problèmes concrets) pour le marché marocain.

Tu déposes ton PDF, tu vois un aperçu réel (score + 2 forces + 2 problèmes). Le paiement est encore désactivé (« bientôt disponible ») — aucun prélèvement.

Lien (peut changer si l’URL temporaire expire) :
https://mizane-4bcpaj3l.b4a.run

Dis-moi franchement : est-ce que l’aperçu t’aide ? Qu’est-ce qui n’est pas clair ?
Merci 🙏
```

Update the URL after each Back4App Redeploy if the hostname changes.

## Product explanation (1 paragraph)

Mizane lit ton fichier CV (PDF/DOCX), extrait le texte, et donne un diagnostic : score global, ATS, structure, mots-clés, expérience. L’aperçu gratuit montre la valeur. Le rapport complet (49 DH) et le CV optimisé (99 DH) arriveront quand le paiement Payzone sera activé — pas pendant cette bêta.

## Recommended test scenario

1. Ouvrir le site en français (mobile + desktop si possible).  
2. Créer un compte ou analyser en session.  
3. Déposer un vrai CV (pas un scan flou si possible).  
4. Noter le poste cible (ex. « Ingénieur QA », « Développeur », « Commercial »).  
5. Lire score + aperçu + message « Paiement bientôt disponible ».  
6. Tester suppression du CV.  
7. Optionnel : même parcours en EN ou AR.

## Feedback questions

1. En 10 secondes, as-tu compris ce que fait Mizane ?  
2. Le score te semble-t-il crédible pour *ton* CV ?  
3. Les 2 problèmes affichés sont-ils actionnables ?  
4. Comprend-tu clairement ce que tu aurais pour **49 DH** vs **99 DH** ?  
5. Qu’est-ce qui freinerait un paiement plus tard ?  
6. As-tu eu un bug (upload, lenteur, page cassée) ?

## Bug reporting

Ask testers to send:

- URL exacte  
- Navigateur / mobile  
- Heure approximative (UTC+1)  
- Capture d’écran  
- Ce qu’ils ont fait juste avant  

To: `bonjour@mizane.ma` (or your preferred inbox).

In-app: page `/retour-beta` (noindex) — short form, no CV upload.

## What you promise testers

- Pas de paiement pendant la bêta publique désactivée  
- Suppression possible du CV  
- Feedback utilisé pour améliorer le produit, pas pour du marketing inventé

# CNDP / Loi 09-08 — checklist propriétaire

Cette liste n’est pas une conformité. Le responsable de traitement (le fondateur / la société) doit :

1. Identifier le traitement : CV, e-mails, paiements, logs techniques.
2. Déposer la formalité CNDP applicable (déclaration / autorisation).
3. Demander une autorisation de transfert si un LLM hors Maroc (OpenAI) reçoit le texte du CV.
4. Tenir un registre : finalités, durées (30 jours pour les CV, plus long pour les pièces de paiement), sous-traitants (Fly.io, Postgres, R2, Cloudflare, Payzone, OpenAI optionnel).
5. Publier la page Confidentialité et honorer accès / rectification / suppression (`privacy@mizane.ma` et « Supprimer mon CV »).

La page interne `/lancement` (noindex) reprend la même liste à côté des gates techniques.
